lin-sing 整合包（Windows / NVIDIA 显卡版）0.1.0-beta
================================================

给一首歌，3D 女孩 lin 就会把它唱出来：口型对字、动作踩拍、自动运镜和字幕，最后导出视频。
全程在你自己的电脑上运行，不联网，不收费，你的歌不会离开这台电脑。


一、你的电脑要满足
------------------
- Windows 10 或 11（64 位）
- NVIDIA 显卡：RTX 20 系 / GTX 16 系或更新，显存 6 GB 以上，并装好最新驱动
- 内存 16 GB 以上，磁盘至少留 10 GB
- 不支持：AMD 显卡（在做了）、Intel 显卡、Mac、没有独立显卡的电脑
  配置不够时，启动程序会直接告诉你哪一项不满足。


二、怎么用
----------
1. 把整个压缩包解压出来（分卷压缩的话，解压第一个文件 .001 就行，其余分卷要放在同一个文件夹里）。
   建议解压到 D:\lin-sing 这样的短路径，不要放在“下载”或桌面的深层文件夹里。
2. 双击“启动 lin-sing.bat”。
   - 第一次启动要检查电脑、准备显卡，大约 1–3 分钟，请耐心等。
   - 如果 Windows 提示“已保护你的电脑”，点“更多信息”→“仍要运行”。
3. 浏览器会自动打开 lin-sing 的页面：
   拖入歌曲 → （可选）粘贴歌词 → 选这首歌的感觉 → 点“生成 lin 的演唱视频”。
   一首 4 分钟左右的歌大约 3–8 分钟出片。
4. 做好后可以在页面里看、下载，或者点“实时播放”在新窗口里带声音看。
5. 用完关掉那个黑色窗口即可。做好的作品都在 songs 文件夹里。


三、歌词怎么写
--------------
- 一行一句，按歌里的顺序。
- 想同时显示翻译，就写成：原文 | 译文
  例：君が生きていたならそれでいい | 只要你活着就好
- 不填也可以，程序会自己听歌词，但可能听错字，所以尽量自己贴歌词。


四、高级模式
------------
- 作品卡片上的“高级编辑”：在时间轴上改每一段的动作、表情，看质检报告，只渲染一小段预览。
- 想让 AI 帮你改：用 Claude Code、Kimi Code 桌面版、Codex 等智能体打开这个文件夹，它们会读 AGENTS.md 来操作 lin-sing。
  （智能体本身需要联网；lin-sing 出片不需要。）


五、常见问题
------------
- 启动时说“没有检测到 NVIDIA 显卡”：确认是 N 卡并到 nvidia.cn 装最新驱动。
- 说“显卡不能运行 AI 模型”：驱动太旧，更新驱动后重启电脑。
- 生成时说“显存不够”：关掉游戏、直播软件、其他 AI 程序后再试，或换一首短一点的歌。
- 歌词对不上：自己贴歌词；翻唱版要贴翻唱版实际唱的词。
- 更多问题见 docs\KNOWN_ISSUES.md。
