lin-sing 整合包 · 干净电脑测试清单
===================================

测试时请拔掉网线、关掉 Wi-Fi（lin-sing 应该完全离线可用）。

1. 解压
   [ ] 所有分卷放在同一个文件夹，解压第一个（.7z.001）成功，没有报错
   [ ] 解压后文件夹里有“启动 lin-sing.bat”“先看我.txt”、runtime、models、player 等

2. 启动（断网状态）
   [ ] 双击“启动 lin-sing.bat”，黑色窗口出现
   [ ] 如果 Windows 提示“已保护你的电脑”：点“更多信息→仍要运行”后能继续（截图提示内容）
   [ ] 黑色窗口里每一项检查都是 [通过]（截图）；如果有 [不满足]，抄下完整文字
   [ ] 浏览器自动打开 lin-sing 页面（没自动打开的话，手动打开窗口里显示的地址）
   第一次启动用时：____ 分钟

3. 生成一首歌（断网状态）
   [ ] 拖入一首 3–5 分钟的歌，粘贴它的歌词，选一个“感觉”，点“生成”
   [ ] 页面上的步骤一步步变成 ✓，最后出现视频
   [ ] 视频里：lin 的嘴和唱的字基本对得上 / 动作跟着节奏 / 字幕在屏幕下方
   [ ] “下载视频”能下载，下载的 mp4 能用电脑自带播放器打开
   [ ] “实时播放”会打开一个新窗口，有声音、有字幕，按 Esc 能关掉
   生成用时：____ 分钟（歌长 ____ 分钟）

4. 故意出错
   [ ] 上传一个超过 10 分钟的音频：页面提示“超过了 10 分钟上限”
   [ ] 把一个 .txt 改名成 .mp3 上传：页面提示“这个音频文件读不了”

5. 高级模式（可选）
   [ ] 作品卡片上点“高级编辑”，能看到时间轴，点一个动作块能改动作，“保存并烘焙”后质检结果更新
